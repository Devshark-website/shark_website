# SHARK Shop — ร้านค้าเกมและสินค้าดิจิทัล (Full-Stack บน GitHub Pages + Supabase)

หน้าร้านและระบบหลังบ้านพร้อมใช้งานจริง:
- **แยกหน้าตามหมวดหมู่จริง:** หน้าแรก (`index.html`), หน้าหมวดหมู่แยกแต่ละหมวด (`category.html?c=...`), หน้าสินค้ารายตัวพร้อมแกลเลอรีรูปตัวอย่างหลายรูปและซูมดูภาพ (`product.html?id=...`), หน้าเติมเงิน (`topup.html`), หน้าบัญชีผู้ใช้ (`account.html`), และหน้าแอดมินหลังร้าน (`admin.html`)
- **ระบบบัญชีผู้เล่นปลอดภัย:** สมัครด้วยอีเมล + ยืนยันรหัส 6 หลักทางอีเมล, **กันชื่อผู้ใช้ซ้ำ** (ตรวจสอบทั้งขณะพิมพ์และระดับฐานข้อมูล), เปลี่ยนรหัสผ่านหรือขอรหัส 6 หลักทางอีเมลเพื่อตั้งรหัสผ่านใหม่ได้
- **กันบอท (Anti-Bot):** ใช้ **Cloudflare Turnstile** ฟรี ทั้งหน้าเข้าสู่ระบบ สมัครสมาชิก และขอรีเซ็ตรหัสผ่าน
- **ระบบเติมเงินใช้ได้จริง:**
  - **พร้อมเพย์ (PromptPay QR):** สร้าง QR มาตรฐาน EMVCo ระบุยอดเงินอัตโนมัติ สแกนได้ทุกแอปธนาคาร + แนบสลิป
  - **ทรูมันนี่ วอลเล็ต (ซองอั่งเปา):** ตรวจสอบรูปแบบลิงก์ซองของขวัญและกันใช้ลิงก์ซ้ำ
  - **โอนผ่านธนาคาร:** ปุ่มคัดลอกเลขบัญชี + แนบสลิป
  - ยอดเงินและสถานะอัปเดตเข้าหน้าเว็บลูกค้าแบบเรียลไทม์ทันทีที่แอดมินกดอนุมัติ
- **ระบบเติมสต็อกสินค้า 2 โหมด:**
  - **ส่งโค้ดอัตโนมัติ:** วางโค้ด/ไอดีบรรทัดละ 1 รายการในหน้าแอดมิน ระบบนับสต็อกและตัดส่งให้ลูกค้าทันทีที่ซื้อ
  - **แอดมินส่งเอง:** ให้ลูกค้ากรอกข้อมูล (เช่น UID เกม) แล้วแอดมินกดส่งงานหรือยกเลิกพร้อมคืนเงินอัตโนมัติ

## เริ่มต้นใช้งาน
1. อ่านขั้นตอนเชื่อมต่อฐานข้อมูลและระบบอีเมล/กันบอทใน **[`SETUP.md`](SETUP.md)**
2. แก้ค่าใน [`js/config.js`](js/config.js)
3. อัปโหลดขึ้น GitHub แล้วเปิด **Settings → Pages → Source: GitHub Actions** (มีไฟล์ `.github/workflows/pages.yml` ให้พร้อมแล้ว)
